TraumaBond — Communication-Based Wellbeing Tracker

HOW TO RUN:
1. Extract this folder.
2. Open it in VS Code.
3. Open index.html in a browser, or use VS Code Live Server.
4. Try a check-in.

CURRENT PROTOTYPE:
- Responsive landing page
- Daily text check-in
- Browser-side keyword-based communication snapshot
- Basic dashboard
- Local check-in counter
- Privacy and non-diagnosis messaging

NEXT DEVELOPMENT:
1. Replace keyword analysis with an NLP emotion/sentiment model.
2. Store time-series features and calculate a personal baseline.
3. Detect significant changes from baseline.
4. Add consent and data deletion controls.
5. Add optional crisis/support resources.
6. Add authentication only if needed; keep data minimization as a priority.

IMPORTANT:
This prototype is a wellbeing reflection tool, not a medical diagnostic system.
